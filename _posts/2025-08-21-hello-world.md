## Introduction {#introduction}

Markdown is a lightweight markup language that lets you format text easily.  
You can write **bold**, *italic*, or `inline code` without touching HTML.

## Features {#features}

Some common features of Markdown:

- Headings: `#`, `##`, `###`  
- Lists:
  - Ordered
  1. Item 1
  2. Item 2
- Links: [Click me](https://example.com)
- Images: ![Alt text](https://via.placeholder.com/150)
